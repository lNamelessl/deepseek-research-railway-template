# DeepSeek Research

Cited deep-research reports from one topic, with live progress. Enter a topic,
watch the deep search run (thinking + up to ~20 server-side searches), and get a
cited markdown report with a shareable link and a markdown export.

One service, one volume, one deploy-time variable. There is no SearXNG service,
no SERP API keys, and no scraping code — the entire retrieval stack (search,
page reading, extraction) runs on DeepSeek's side via the `deepseek_web_search`
server tool, and the report text is generated by `deepseek-flash` with thinking
enabled.

## Workflow

1. `GET /` — topic form (plus a short list of recent reports).
2. `POST /research` — validates the topic, enforces the one-report-at-a-time
   lock, stores a running row, starts the background generation, and redirects
   to `/reports/<id>`.
3. `/reports/<id>` shows live SSE progress while the report runs:
   `searching… (n tool calls)` → `thinking…` → `writing…`. You can leave the
   page and come back to the same link at any time.
4. When the report finishes, the same URL renders the cited markdown report
   (sanitized, XSS-safe) with a sources list, usage and estimated cost.
5. `GET /reports/<id>/export.md` downloads the raw markdown.
6. `GET /health` is the healthcheck probe (dotless, no external calls).

## Variables

| Variable | Required | Meaning |
|---|---|---|
| `DEEPSEEK_API_KEY` | yes | Your DeepSeek key from platform.deepseek.com. Deep reports cost roughly $0.02–0.05 each (searches + tokens), billed to your account. The service boots healthy without it; report creation returns a clear error until it is set. |
| `APP_ACCESS_PASSWORD` | no | When set, report **creation** requires this password (the deploy form generates one via `${{secret(24)}}`). Reading reports via their unguessable `/reports/<id>` links stays open. |
| `MAX_REPORTS` | no | FIFO retention cap for finished reports (default 100). Oldest finished reports are pruned after each new one. |
| `MAX_OUTPUT_TOKENS` | no | Output budget per report (default 12000). Thinking consumes the same budget as report text; a report that hits the budget is stored but flagged as truncated. |

## Cost and time honesty

- Deep reports take **a few minutes** and roughly **5–20 searches** per report.
- Search and page fetch are **$0.75 per 1,000 uses**; `deepseek-flash` tokens are
  $0.30/1M input and $1.20/1M output at peak (01:00–04:00 and 06:00–10:00 UTC
  Mon–Fri are half price; cache hits cost a fraction of the miss price).
- A typical report lands around **$0.02–0.05**. The finished page shows the
  measured usage (searches, fetches, tokens) and an estimated cost at list rates.
- **One report runs at a time.** While a report is generating, other attempts
  get a friendly 429 page ("try again shortly").

## Safety and rendering

- `safety_check: {"level": "high"}` is **on by default** for every research call.
  DeepSeek's provider-side safety review is the deployer's ToS duty for
  public-facing deployments; this app enables it out of the box and surfaces a
  refusal as a clean "report declined" page.
- Report markdown is rendered with `markdown-it-py` in its JS-default preset
  (raw HTML **disabled** — model-emitted HTML is escaped, never executed) plus
  the default link validator (javascript: hrefs rejected) and http(s)-only
  citation URLs. Topics and report content are user/model text; they cannot
  inject script into the page.
- The only outbound host is `https://api.deepseek.com`.

## Persistence

SQLite (stdlib `sqlite3`, single file) lives on the `/data` volume — reports
survive redeploys and restarts. A restart marks any in-flight report as failed
(generation is in-process by design: one at a time, single worker).

## Local development

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
DATA_DIR=./data .venv/bin/uvicorn app.main:app --port 8000
```

Without `DEEPSEEK_API_KEY` the UI works and `/health` is healthy; creating a
report returns the "key not set" error page. Point `DEEPSEEK_BASE_URL` at a
mock upstream to exercise the streaming parser without spend.
